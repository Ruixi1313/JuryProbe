# Guardrail Robustness v1

Frozen no-API robustness analyses for the JuryProbe guardrail paper.

Included analyses:

- threshold sensitivity for high-risk designation
- calibration-risk statistics, including grounded specificity control
- Random-Routed stability over repeated random routing trials
- leave-one-judge-out two-judge subpanel diagnostics

This artifact does not change the main policy definition, risk thresholds, routing logic, or primary guardrail results.
